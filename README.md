 Dynamic Portfolio & Resume CMS
A robust, secure, and fully dynamic ASP.NET Core MVC system designed with a strict N-Tier Architecture.

 Tech Stack & Architecture
Backend: C#, .NET Core, Entity Framework Core (Code-First), LINQ.

Frontend: JavaScript (AJAX/jQuery), Bootstrap, DataTables.

Architecture: N-Tier (Domain, Application, Infra, Web) with Dependency Injection (IoC).

 Top Technical Highlights
Asynchronous Admin Panel: Fully SPA-like experience using AJAX/jQuery for CRUD operations (No page reloads).

Security First: * XSS Protection: HTML Sanitization on user inputs.

Bot Shield: Integrated Google reCAPTCHA v3.

Secure Uploads: Strict MIME-type & extension validation to prevent malicious execution.

Clean Code: Strict Separation of Concerns (SoC) across 5 distinct layers.
